How to get this?
Where to generate your API token in Canvas:
  1. Log in to your Canvas instance (e.g. canvas.bham.ac.uk).
  2. Click your profile icon on the left navigation bar $\rightarrow$ Settings.
  3. Scroll down to Approved Integrations and click + New Access Token.
  4. Give it a purpose (e.g., Modula) and generate. Copy and paste the token here!
