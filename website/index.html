QUICK START GUIDE

Up and running in 60 seconds

No complex configuration. Connect with your Canvas account and start studying offline.

01

Generate Token in Canvas

Log in to your university Canvas web portal, click Account in the sidebar → Settings → scroll to Approved Integrations and click + New Access Token.

Give it a purpose (e.g., "Modula") and copy the generated key.
02

Paste in Modula Settings

Open Modula, paste your university's Canvas URL (e.g. https://canvas.bham.ac.uk) and your access token into the Settings modal, then click Save & Connect.

Select your download directory (default: ~/Downloads/Modula).
03

Browse, Sync & Download

All your enrolled courses and modules appear instantly. Click Download Module or Download All Modules to save everything locally for exam prep.

Modula will continue to auto-sync new slides in the background.

A NOTE FROM THE DEVELOPER
Open Source · Non-Profit

Why do Windows & Mac show warnings on first launch?

Commercial operating systems require developers to purchase expensive corporate certificates to eliminate automated security prompts: Apple charges $99 every single year for an Apple Developer Program subscription, while Microsoft requires hardware-token EV Code Signing certificates that cost $300 to $500+ every year.

Modula is an independent, 100% free tool built by university students for university students to make Canvas course downloads frictionless. As an independent student developer, I refuse to place paywalls, collect user data, or pay hundreds of dollars every year to commercial tech giants for corporate certificates.

Automated Warnings ≠ Malware: Prompts such as "Windows protected your PC / Unknown Publisher" or "Modula is damaged and can't be opened" are triggered solely because the software is unsigned with a paid commercial certificate. They are not security detections.

IF USING SETUP INSTALLER
Option B: Allow Quarantined Binary in Windows Security

Windows Defender's real-time heuristic scanner occasionally quarantines newly extracted unsigned .exe files during installation before the shortcut can link to it.

  1. Open Windows Security from the Start menu.
  2. Click Virus & threat protection → Protection history.
  3. Click on the quarantined item, click Actions, and select Allow on device or Restore.
Why this occurs: Windows Defender's real-time protection occasionally quarantines the newly unpacked binary into protection history while NSIS is completing the setup, making the desktop shortcut unable to find the executable. Both options above permanently resolve this.
macOS Fix

Bypassing macOS Gatekeeper ("Damaged / Can't be opened")

When downloading applications outside the Apple App Store without a $99/year Apple Developer membership, macOS places the downloaded app into quarantine and shows "Modula is damaged and can't be opened".

FASTEST · 1-CLICK TERMINAL COMMAND
Method 1: Clear Quarantine via Terminal

Open Terminal (Press Cmd + Space, type Terminal, press Enter) and paste this one-time command:

xattr -cr /Applications/Modula.app
GUI METHOD · NO TERMINAL
Method 2: Right-Click in Finder
  1. Drag Modula into your /Applications folder.
  2. Right-click (or hold Control and click) on Modula.app.
  3. Click Open from the contextual menu.
  4. In the dialog that appears, click the newly visible Open button.
SETTINGS METHOD
Method 3: System Settings "Open Anyway"
  1. Open System Settings → Privacy & Security.
  2. Scroll down to the Security section.
  3. Under "Modula was blocked", click Open Anyway.
